# MotionCare Fyzio – demo web

Demo web pre fiktívne fyzioterapeutické štúdio **MotionCare Fyzio**.

Tento projekt slúži ako ukážka balíka **Web s online rezerváciou**.

## Obsah

- HTML/CSS/JS statický web
- Bookio placeholder link
- kontaktný formulár pripravený pre Web3Forms
- mapa cez Google Maps iframe
- responzívna verzia

## Bookio

V deme je všade použitý placeholder link `https://www.bookio.com/`. Pri reálnom klientovi treba vytvoriť/nastaviť Bookio účet, získať rezervačný link a nahradiť placeholder.
